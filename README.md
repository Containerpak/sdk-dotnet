# .NET SDK (cpak)

.NET SDK 9.0.317 for cpak development environments. The package includes the C# compiler, .NET runtime, MSBuild, NuGet and project templates for amd64 and arm64.

```bash
cpak install github.com/containerpak/sdk-dotnet
```

```bash
cpak run github.com/containerpak/sdk-dotnet dotnet -- --info
```
